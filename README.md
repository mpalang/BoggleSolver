# BoggleSolver

A Program that solves a known Boggle configuration and shows all possible words.
V0.3.0



Takes a picture of a boggle board, recognizes the board, the dice and then reads the letters.

It then finds the possible words according to Boggle rules.

To get reliable board recognition make sure there is no orange around the board, the picture is taken straight from above and minimize the shade on the board.



words\_180k from: https://github.com/redbo/scrabble/blob/master/dictionary.txt
words\_400k from: https://github.com/dwyl/english-words/blob/master/words\_alpha.txt
